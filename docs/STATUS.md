# 开发状态与验证边界

## 当前版本 0.16.0

启动先显示难度平板，五档难度可手选或随机选择，当前会话重载与检查点重试保留选择。战役、自由战斗和创造模式是不同玩法入口，规则并未完全统一。

战役已有集结、防守、推进、占领敌方核心的阶段流程。创造模式提供 100×100 米场地、双方兵种、机甲、炮台、装备抽取、训练、锻造和命名存档。创造模式最大 120 个同时活动单位，超出排队；并非无限数量同时运行。创造模式难度敌人数为 10 / 16 / 27 / 20 / 39。背包扩容与出售备件已有初步实现。

## 已知未完成

- 没有联网、服务端、在线匹配；情报文字只在本机显示。
- 机甲为 AI 战斗单位，没有玩家驾驶操作。训练、锻造是面板交互，没有完整室内空间。
- 大量角色、建筑和武器为程序几何体，动画、美术、音效混音和用户体验仍需系统升级。
- 创造模式选择面板位置尚未统一，武器抽取存在旧枪模型残留问题。
- 不包含“世界上所有的枪”，也没有完成完整商业数值与经济体系。
- Windows 尚未导出和实机验证；macOS 包为本地临时签名，没有 Apple 公证。

下一阶段先建立可重复完整回归和性能基线，再统一战役与创造模式的数据、操作提示和装备规则，随后做一张高质量地图的完整体验验证。联机、商业化和大规模美术升级独立立项。
