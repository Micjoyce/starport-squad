# 星港小队 0.7 测试报告

日期：2026-10-25。引擎与导出模板：Godot 4.5 stable 官方版本。

## 功能验证

正式 macOS 应用通过 **268 项自动集成检查，0 项失败**。测试和渲染日志未发现脚本错误或警告。

新增攻城检查覆盖：

- 敌方独立城堡及真实防弹墙；寻路连通双方门洞，玩家沿路径实际穿越战场进入敌方核心。
- 守卫指令把队伍锚定在我方城堡；玩家离开时守卫实际留守。进攻指令后，守卫实际离开城堡跟随头领。
- 留守士兵发现入侵者并阻止敌方占领；无守卫时我方危险进度增加，玩家返回可暂停危险，清除入侵者后危险下降。
- 单纯消灭全场敌人不会自动赢下攻城；附近活守军争夺核心、暂停冻结进度、离开核心进度衰减、友军也能占领。
- 超级噩梦首领限制；8 秒占领获胜及一百万金币只领取一次；我方无人防守被占 20 秒会失败，已有金币保留。

原有装备、价格、技能、存档、四种难度、枪械、近战、手榴弹、城堡升级、十人招募、战利品箱、世界奖杯、跨区与两倍面积科技区检查继续通过。旧玩法检查隔离了自动攻城结算，再单独测试新的攻防结算，避免站位测试意外触发胜负。

## 实机渲染与性能

设备为 Apple M5 Pro，24 GB 内存，1,280 × 800。正式导出应用运行超级噩梦，初始 **31 名敌军＋10 名友军**，双城与核心占领逻辑运行。1,200 帧连续采样包括移动、射击、换弹及士兵战斗，同时最多 2 枚手榴弹。

| 指标 | 结果 |
|---|---:|
| 平均帧率 | 118.2 FPS |
| p95 帧耗时 | 9.09 ms |
| p99 帧耗时 | 10.61 ms |
| 采样末帧绘制调用 | 2,107 |
| 采样末帧渲染对象 | 2,423 |

指定设备和场景结果，不代表其他机器或长时间运行的最低帧率。最终界面另调整了提示条位置，避免遮住占领进度。正式应用的敌方城堡、驻守界面、占领进度和攻城胜利画面已检查。

## 范围与交付

macOS Universal 应用包含 Apple Silicon 与 Intel，实际运行验证在 Apple Silicon 完成；本地临时签名严格校验通过，未做 Apple 公证。源码导出设置不含本机模板绝对路径。

本版为单机机器人对战。双城位置固定，城墙不可破坏；玩家向整支十人小队发布守卫或跟随进攻指令，没有单兵单独命令。枪械目录保留八种近似模型。

演示截图使用隔离测试角色，脚本安排单位位置和试用金币以展示流程，不覆盖玩家正式存档。正常游戏使用实际战斗和占领计时。
