# 星港小队 0.8 测试报告

日期：2026-10-25。Godot 4.5 stable 官方引擎与 macOS 官方导出模板。

## 功能验证

最终正式应用：**294 项自动集成检查通过，0 项失败**。测试与渲染日志没有脚本错误或警告。

新增检查覆盖：普通敌人同步玩家盔甲、大小、裤装款式和风衣；在场士兵换装更新、新增援立即继承穿戴；换装保留已受伤的护甲比例；第五种难度可选择；玩家、二十名普通敌兵、一名精英及十名队友的真实大型彩虹装备；临时装备不覆盖仓库，切换难度恢复原穿戴；临时裤装防御实际生效。

精英检查覆盖：击败只掉一个箱子并只启动一次计时；暂停冻结倒计时；十秒后真实恢复单位和生命；不复制活着的精英；连续多次重生；核心占领期间等待安全部署；不会刷在玩家身上；攻防状态选择、受威胁回防、可达且遮挡视线的掩体选择、可见交火时侧移；胜负结束后停止重生。

旧有双城攻防、士兵指令、占领计时和奖励、城堡升级、枪械、近战、装备买卖、存档、背包、技能、战利品箱、手榴弹、传送与科技区等检查继续通过。旧的“超级噩梦固定二十名红甲士兵”断言已更新为本次要求的“二十名普通士兵同步玩家穿戴”，首领仍使用彩虹套装。

## 实机渲染和性能

在 Apple M5 Pro、24 GB 内存、1,280 × 800 下运行正式应用的「超级困难」，初始 **31 名敌军＋10 名友军**。1,200 帧采样包含实际移动、射击、换弹、队伍交战、精英战术、双城和手榴弹，同时最多出现 9 枚手榴弹。

| 指标 | 结果 |
|---|---:|
| 平均帧率 | 119.2 FPS |
| p95 帧耗时 | 8.33 ms |
| p99 帧耗时 | 9.09 ms |
| 采样末帧绘制调用 | 2,891 |
| 采样末帧渲染对象 | 3,218 |

性能结果只代表该设备和采样场景。正式导出的五难度菜单、全员彩虹套装、精英生命条、重生倒计时与重新出现画面已检查。演示使用隔离档，脚本安排站位和试用装备，没有修改正式玩家存档。
