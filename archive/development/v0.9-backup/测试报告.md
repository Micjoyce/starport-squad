# 星港小队 0.9 测试报告

日期：2026-10-25。Godot 4.5 stable 官方引擎与官方 macOS 导出模板。

## 功能结果

正式应用的 **334 项自动集成检查通过，0 项失败**。正式测试、渲染、演示日志没有脚本错误或警告。

新增检查包含：

- 消音器购买、重复购买拒绝、实际枪管显示；备用射速芯片购买、首级 ×20、后续两芯片融合、等级上限；真实弹夹容量、极限射速每物理帧多发子弹、每秒 1,200 发模拟上限；五种虚构毫米弹药循环选择；金币不足完整回滚；真实商店按钮回调。
- 消音器、弹夹、芯片和宠物训练实际保存到磁盘再读取；旧档增加免费狗但保留原余额；战马领养、喂养、开蛋经验、重复开蛋拒绝。
- 5,000 次独立随机掉落采样符合配置，红蛋保证掉落；敌人真实死亡箱内生成宠物蛋，领取后永久保存。
- 玩家与敌人护甲耗尽时同次命中不扣核心生命，之后命中扣生命；破甲实际生成碎片；Q 提升真实生命到 999；极限连发彩虹激光同一物理帧不能清空全部核心生命。
- 零库存也可投掷无限手榴弹；火箭真实飞行和碰撞爆炸；狗实际咬伤敌人；马实际击碎护甲；士兵有人类面孔与独立战术状态，普通士兵换弹时会选择有实际遮挡且可达的掩体。
- 士兵召唤子代、子代继续召唤孙代；我方 30、敌方普通兵 40 的并发上限；每秒生成预算防止单帧扩散。

原有穿戴同步、精英重生、双城指令、占领胜负、百万奖励、五难度、装备交易、存档迁移、战利品箱、两地区传送等检查继续通过。针对新需求，旧检查更新为“护甲破碎后保留生命”“非彩虹甲也可 Q 强化”“彩虹激光为持续伤害”和“手榴弹不消耗库存”；测试击败单位时分别执行破甲和生命伤害。

## 满编实机性能

正式应用，Apple M5 Pro、24 GB 内存、1,280 × 800，「超级困难」。初始 **41 名敌方单位（40 普通兵＋1 精英）与 30 名友军**，有宠物、独立战术、自动召唤、极限射速改装、双城、街区建筑及火箭。1,200 帧连续采样包含移动、射击、换弹和交战，同时最多 4 枚手榴弹／火箭。

| 指标 | 结果 |
|---|---:|
| 平均帧率 | 113.1 FPS |
| p95 帧耗时 | 10.67 ms |
| p99 帧耗时 | 12.58 ms |
| 采样末帧绘制调用 | 2,755 |
| 采样末帧渲染对象 | 2,894 |

这是指定设备、分辨率和采样场景的结果，不代表其他硬件或长期运行的最低帧率。宠物、士兵面孔、改装店、宠物店、彩虹激光和敌方街区实机画面已检查。并发人数、生成预算、射击模拟、光线合并与碎片预算用于控制开销。

## 解释与范围

概率原话有重复，当前采用基础 20%、白 20%、蓝 30%、紫 50%、金 46%、红 100%，逐项独立判定，并在操作说明中明确这一解释。

毫米弹药是虚构游戏选项。士兵采用规则驱动 AI，不能声称复制真人智商。召唤代数和手榴弹储量无限，同时在场的人数与投射物有上限。敌方城市表现为现有战场里的工业楼群，没有扩成开放世界。画面使用程序化玩具风格几何模型，无血腥。

应用为 macOS Universal，包含 Apple Silicon 与 Intel；实际运行验证在 Apple Silicon。本地临时签名严格校验通过，未经 Apple 公证。源工程不含本机模板绝对路径。演示使用隔离档、试用金币和安排的站位，不覆盖正式玩家存档。
